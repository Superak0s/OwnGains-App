## How to install

OwnGains is an Android app. You install it straight from the OwnGains GitHub releases page, not from the Play Store.

### 1. Download the APK

Under **Assets** below, tap the file for your phone:

- **`OwnGains-v{{VERSION}}-arm64-v8a.apk`**: pick this one if you're not sure. It works on almost every phone made since about 2017.
- **`OwnGains-v{{VERSION}}-armeabi-v7a.apk`**: only for older 32-bit phones. Use it if the other file says *"App not installed"* or *"There was a problem parsing the package"*. Some releases don't include it.

You can skip the *Source code* files. They aren't needed to install the app.

### 2. Allow installs from your browser

The first time you open an APK, Android asks for permission to install apps from unknown sources.

1. Open the downloaded file from the notification, or from **Files → Downloads**.
2. When Android says *"For your security, your phone is not allowed to install unknown apps from this source"*, tap **Settings**.
3. Turn on **Allow from this source**, then go back.

The exact wording depends on your phone. On Samsung it's under **Settings → Apps → ⋮ → Special access → Install unknown apps**.

### 3. Install

Tap **Install**. If Play Protect warns that it doesn't recognise the app, tap **More details → Install anyway**. It shows this warning because the app wasn't installed from the Play Store.

### Updating

Download the newer APK and install it over the existing app. The app keeps your data. Don't uninstall first, because that deletes the data stored on your phone.
